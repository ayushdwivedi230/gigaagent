# GigaAgent 3.0 release notes (pre-release — not yet verified on Windows)
## 3.0.0
**Added:** streaming answers with Stop; Quick/Natural/Structured/Deep-dive formats; Simplify/Expand/Example/Rephrase/Regenerate; speaking-time estimate and 30/60/90 s targets; mode tools (interview, meeting, study, general); library (answers, notes, prompts, preparation profiles); transcript search; session export (Markdown/text/JSON); DB backup; delete-all; pause/resume; mic selection + level meters; compact and three-panel workspace with resizable, collapsible, remembered panels; themes (dark/light/high-contrast/system), accents, text scale; global + in-window shortcuts; privacy switches; diagnostics panel.
**Changed:** Ghost Mode is a visible state machine with honest limits; app renamed GigaAgent (was "AI Meeting Assistant"); Gemini model chain updated.
**Fixed:** see PROJECT_AUDIT.md (11 defects).
**Removed:** canned fallback answers; PowerShell affinity call; unused legacy components.
