# Security report
**Verified in code/tests:** contextIsolation + sandbox + no nodeIntegration; CSP in production; IPC sender+frame check and input validation on every channel (bounded sizes, id patterns, enum checks); navigation restricted to the app bundle; external links https-only without credentials; `<webview>` blocked; camera never granted; API keys main-process only, OS-encrypted or memory-only, masked to the renderer, header-only to Gemini, never logged; user-facing errors exclude response bodies; Markdown cannot inject HTML; LIKE wildcards escaped; prototype-pollution keys dropped in settings merge; cloud AI / screenshot / transcription switches enforced in main.
**Not done:** `npm audit` (no registry access here — run it); code signing; Deepgram key travels as the sources already implemented it (unchanged); settings file and DB are not encrypted at rest (only keys are); no fuzzing of IPC.
**Ghost Mode:** capture-exclusion flag only. No anti-proctoring, process concealment or detection evasion exists or was added.
